## Security boundary

The shell hook denies literal `nxr trust approve-policy`, `nxr trust add`, `nxr trust revoke`, and any command that names `trusted-projects.json`. That is not a sandbox. A process running as the same user can still write the trust database. `NXR_TRUST_PROJECT=1` still grants one-shot trust. `set_trust_db_override` can retarget the database inside one process. The policy digest only rejects an unapproved file on the normal NXR path. This release does not add a second approval mechanism.
